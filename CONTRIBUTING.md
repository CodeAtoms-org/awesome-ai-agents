# Contributing to Awesome AI Agents

First off, thank you for considering contributing to Awesome AI Agents! It's people like you that make this a great resource for the community.

## How to Contribute

We welcome contributions in the form of new AI agents, tools, or resources. To contribute, please follow these steps:

1.  **Search for existing entries**: Before adding a new resource, please check if it's already listed in the `README.md`.
2.  **Ensure quality**: We only include high-quality, reliable, and well-maintained resources.
3.  **Fork the repository**: Create a fork of this repository on GitHub.
4.  **Make your changes**: Add your resource to the appropriate section in `README.md`.
5.  **Commit your changes**: Provide a clear and concise commit message.
6.  **Submit a Pull Request**: Submit a Pull Request to the `main` branch of this repository.

## Contribution Guidelines

- **Formatting**: Please follow the existing formatting style in `README.md`.
  - Use the format: `- [Name](URL) - Description.`
  - Keep descriptions concise and objective.
- **Categorization**: Place your resource in the most relevant section. If a suitable section doesn't exist, feel free to suggest a new one.
- **Links**: Ensure all links are valid and point to the official source (e.g., GitHub repository, official website).

## Pull Request Process

1.  Ensure your PR follows the contribution guidelines.
2.  Provide a brief description of what you're adding and why it's useful.
3.  A maintainer will review your PR and provide feedback as needed.
4.  Once approved, your PR will be merged into the `main` branch.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). (Note: Please refer to a standard version until a local one is provided).

Thank you for your contributions!
